# Backend

Repository ini berisi layanan backend untuk platform deteksi kelengkapan APD.

Cakupannya meliputi API, autentikasi, pemrosesan video, integrasi model computer vision, aturan status kepatuhan, penyimpanan hasil, dan riwayat analisis. Implementasi diarahkan modular agar model serta konfigurasi industri dapat dikembangkan lebih lanjut.
